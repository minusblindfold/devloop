# Devloop Ecosystem

> Linked repositories for cross-repo context during research and planning.

devloop is a Claude Code plugin for structured development workflows. It is part of an ecosystem of three repositories:

- **devenv** — Terminal companion tools for browsing devloop artifacts (`view-plan`, `view-design`, `view-research`, `view-implement`, `open-diagrams`, `claude-context`).
- **devloop-rules** — Rule packs that provide coding patterns, project structure conventions, and stack definitions for use with devloop skills.
